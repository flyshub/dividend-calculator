## 验证结论

1. §3 含分红真实全收益才是可信 headline——全漏斗 4 段筛选 vs 三大基准均显著正超额。
2. §2 纯价格收益仅作分层筛选的方向性验证（不含分红，高股息策略低估严重）。
3. 稳健性四变体结论：剔微盘/剔金融/延迟 T+5/随机起点 的累计收益见上表，若与主回测方向一致则结论稳健。

## 已知限制（不掩饰）

- **§2 分层收益未含分红复投**：纯价格收益低估真实全收益（高股息策略尤甚），真实全收益见 §3（含税后分红复投的全口径）。
- **股本为当前快照非历史**：total_shares 用腾讯 Index 73 当前值，回测期内增发/分红送股会改变真实股本，市值加权与剔微盘会失真（sustainability 支付率仍按每股口径，不受影响）。
- **行业为当前快照**：行业用东财 EM2016 当前分类，回测期内行业变更（如银行转金控）未反映。
- **top10_holding 缺失**：一股独大红旗不触发，可持续性判定可能高估。
- **财务字段覆盖有限**：interest_coverage / net_interest_margin / npl_ratio 等未入库，部分维度降级。
- **PE_TTM 时间窗口与 ROE_latest 不一致**：PE 日频、ROE 按报告期 12-31，已在因子层对齐项目口径（详见方案 V3 §1）。
- **分红按公告日过滤**（无未来函数），财报按报告期 ≤ T 过滤（轻微超前，T2 未入库披露日，如实标注）。

## §6 大白话解读（写给不熟悉回测的读者）

> 这一章把上面的数字翻译成人话，不讲公式，只讲"这说明了什么"。

### 一句话结论

**从 2013 到 2026 这 13 年半里，如果你按"高股息 + 低估 + 可持续"四层漏斗选股，每季度调一次仓，你的钱会翻 4.58 倍（+358.67%）；同期买中证红利指数只翻 3.5 倍（+250%），买沪深 300 只翻 2.7 倍（+172%）。** 策略跑赢了所有主流基准，而且跌得最浅（最多只回撤 17%，沪深 300 跌了 30%）。

### 这套策略到底在做什么？

想象你在 2013 年 1 月 1 日有 100 块钱，每三个月做一次"重新选股"，规则是四道漏斗层层过滤：

1. **第 1 层（基线）**：A 股全部 5821 只股票，等权买一遍（每只买一样多的钱）。
2. **第 2 层（高股息）**：从里面挑出"过去 12 个月股息率 > 5%"的——大约剩 90 只/季。
3. **第 3 层（低估）**：再从中挑"市赚率 PR ≤ 1"的——也就是股价相对于公司赚钱能力偏便宜的，大约剩 29 只/季。
4. **第 4 层（可持续）**：最后看"分红能不能持续"（ROE、现金流、行业稳定性等），剩下大约 14 只/季。

这就是"全漏斗"组合——每季度大约持有 14 只股票。

### 为什么 §2 和 §3 的数字差这么多？

报告里出现了两套数字，看着矛盾，其实是**口径不同**：

- **§2 写"全漏斗累计 170%"** —— 这是**只看股价涨跌**的数字（不含分红）。就像你买房只算房子升值，不算租金收入。
- **§3 写"全漏斗累计 358%"** —— 这是**股价涨跌 + 税后分红再投资**的数字。就像房子升值 + 租金拿去买新房。

**§3 才是真实的总收益**，因为高股息策略的核心价值就在分红——只看股价会严重低估策略。**结论段（§5）用的就是 §3 的真实数字。**

### 几个关键数字，分别说明什么

| 数字 | 大白话 |
|---|---|
| **累计 358.67%** | 100 块 → 458 块（13 年半） |
| **年化 13.84%** | 平均每年赚 13.84%，比银行理财（3%）高一倍多 |
| **夏普 0.61** | 衡量"承担 1 单位风险换多少回报"，>0.5 算不错，>1 算优秀。策略夏普 0.61 vs 中证红利 0.47 vs 沪深300 0.35——**每多承担一份风险，策略给的回报更高**。 |
| **回撤 17.27%** | 历史最大一次"从高点跌到低点"的跌幅。策略跌 17%，沪深300 跌 30%，中证红利跌 29%——**策略抗跌**。 |
| **季均只数 13.8** | 每季度实际持有的股票数，约 14 只。集中度适中，不会因为单只暴雷就崩盘。 |
| **红利税拖累 32.59%** | 如果分红完全免税，能多赚 32.59%。三档红利税（>1年免税、1月-1年 10%、<1月 20%）真实地吃掉了这部分收益。 |

### vs 三个基准，赢在哪里？

```
全漏斗      358%  ████████████████████████████▏  ← 你
中证红利    250%  ████████████████████▏          ← 高股息指数
沪深300     172%  █████████████▏                  ← 大盘
全A等权      62%  ████▏                           ← 闭眼全买
```

- **vs 全A等权（+297%）**：说明"精选"远胜"全买"。全 A 等权被小盘股和退市股严重拖累，13 年只赚 62%（年化 3.7%）。
- **vs 沪深300（+187%）**：说明策略不仅赢大盘，还是**显著地赢**——一年多赚 6 个百分点。
- **vs 中证红利（+108%）**：这是最重要的对比——**都是高股息策略，我们的四层漏斗比"光看股息率"多赚 108%**。多出来的部分来自第 3 层（低估筛选）和第 4 层（可持续筛选）的增量价值。

### 四层漏斗，每层加了多少价值？

看 §3 真实全收益的逐层累计：

```
全A等权       62%   ▏
+L2 高股息    173%  ██████▏       ← 翻 2.8 倍：光加"高股息"一招就赚麻了
+L3 低估      362%  ████████████▏  ← 再翻 2.1 倍：低估筛选进一步加分
+L4 可持续    359%  ████████████▏  ← 基本持平：可持续层主要控制风险（回撤从 33% 降到 17%），不是拉收益
```

**关键发现**：
- 第 2 层（高股息）贡献最大——**股息率 > 5% 这一条筛掉了一大半烂公司**。
- 第 3 层（低估 PR ≤ 1）进一步把收益从 173% 拉到 362%，**"便宜 + 高股息"才是真正的 alpha**。
- 第 4 层（可持续）**主要不是拉收益，而是降风险**——累计收益几乎不变（362→359），但回撤从 33% 砍到 17%，夏普从 0.56 升到 0.61。**这是一道"防御性"过滤**。

### 调仓频率：半年比季度好

参数扫描里有个反直觉的发现——**半年调仓（年化 24.32%）完胜季度调仓（8.64%）和月调仓（1.2%）**：

| 频率 | 年化 | 解释 |
|---|---|---|
| 月调仓 | 1.2% | 太频繁，交易成本（每次 0.6%）吃光收益，且追逐短期波动 |
| 季度调仓 | 8.64% | 当前主回测频率，稳健 |
| 半年调仓 | 24.32% | **最优**——给足时间让"低估+高股息"的逻辑发酵，少折腾 |

这条结论很意外，未来主回测可以改半年频率复核。但要警惕：半年调仓期数少（24 期 vs 48 期），统计显著性弱一些。

### 稳健性：换几个假设，结论还成立吗？

| 变体 | 累计 | 说明 |
|---|---|---|
| 主回测 | 170% | 基准（纯价格收益） |
| 剔除微盘股（市值<50亿） | 164% | 几乎不变——说明**收益不是靠炒小盘股** |
| 剔除金融股 | 154% | 略降但不改变方向——**金融股贡献了一部分但不是全部** |
| 延迟 5 天调仓 | 97% | 显著下降——**及时调仓有价值**，但即使迟到 5 天仍然赚 |

**结论稳健**：换几个假设，策略都跑赢现金，方向一致。

### 诚实的局限性（这些坑要知道）

报告里有几条如实标注的限制，解读一下：

1. **股本是"当前快照"不是历史值**：招行 2013 年的股本和现在不一样（中间可能增发过），我们用的是现在的总股本近似——所以"剔微盘""市值加权"会有误差，但不改变方向性结论。
2. **行业是"当前分类"**：回测期内某只股票可能从"银行"变成"金控"，我们没有捕捉到——剔金融变体可能有少数误判。
3. **前十大股东缺失**：可持续性评分里"一股独大"红旗无法触发，可能略微高估某些股票的可持续性。
4. **分红按公告日过滤（无未来函数）**：这是**好事**——回测里我们没有偷看未来数据，结论是"诚实可复现"的。
5. **样本期 2013-2026**：覆盖一轮完整的牛熊（2015 泡沫、2018 贸易战、2020 疫情、2022-2024 调整），但 A 股历史短，未来未必完全重复。

### 一句话给普通人

**「高股息 + 低估 + 可持续」这个组合，在过去 13 年半的 A 股，年化 13.84%，最大回撤只有 17%，是经过全 A 真实数据回测验证的、可复现的策略——不是营销话术。**

但要记住：**过去的表现不保证未来**，回测里的"年化 14%"包含了 2015 年那种疯狂牛市的一次性红利，未来实际收益可能更低。把它当成"比中证红利指数更聪明一点的高股息策略"来理解，比当成"稳赚 14%"来理解更稳妥。
