## §5 结论与限制

**全漏斗真实全收益（含税后分红复投）：累计 184.34%，年化 8.20%，夏普 0.35，回撤 39.18%。**

- vs 中证红利全收益（主基准）：累计超额 **-66.27%**
- vs 沪深300全收益：累计超额 **12.46%**
- vs 全A等权：累计超额 **-44.69%**

## 验证结论

1. §3 含分红真实全收益才是可信 headline。显著性检验（t 检验 + bootstrap，见 scripts/backtest_significance.py）：全漏斗 vs 全A基线 49 期逐期均值 +2.05%，t=0.904，p=0.366，bootstrap 95% CI [-1.62%, +7.42%]，**未达统计显著**——方向为正、不能断言显著超额，结论按此如实表述。
2. §2 纯价格收益仅作分层筛选的方向性验证（不含分红，高股息策略低估严重）。
3. 稳健性变体结论：剔微盘/剔金融/延迟 T+5 的累计收益见上表，若与主回测方向一致则结论稳健；随机起点敏感性见 §3.2 下方说明。

## 已知限制（不掩饰）

- **§2 分层收益未含分红复投**：纯价格收益低估真实全收益（高股息策略尤甚），真实全收益见 §3（含税后分红复投的全口径）。
- **股本为当前快照非历史**：total_shares 用腾讯 Index 73 当前值，回测期内增发/分红送股会改变真实股本，市值加权与剔微盘会失真（sustainability 支付率仍按每股口径，不受影响）。
- **行业为当前快照**：行业用东财 EM2016 当前分类，回测期内行业变更（如银行转金控）未反映。
- **top10_holding 缺失**：一股独大红旗不触发，可持续性判定可能高估。
- **财务字段覆盖有限**：interest_coverage / net_interest_margin / npl_ratio 等未入库，部分维度降级。
- **PE_TTM 时间窗口与 ROE_latest 不一致**：PE 日频、ROE 按披露日过滤，已在因子层对齐项目口径（详见方案 V3 §1）。
- **分红按公告日过滤**（无未来函数），财报按披露日（NOTICE_DATE）过滤（T11 已入库披露日，无超前）。
