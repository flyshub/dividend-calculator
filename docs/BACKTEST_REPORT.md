## 一、回测目的

验证项目核心假设：「市赚率 PR < 0.8 买入能赚钱」是否有实证依据。

- **PR = PE_TTM / ROE_latest**（与 `pr.py` 口径一致：ROE 取最新已披露年报，非 5 年 ROE 中位数）
- 结论驱动后续：PR 有 alpha → 做行业中性化/组合构建（#27）；证伪 → 转向 FCF yield/魔法公式

## 二、方法论

### 口径设计

| 项    | 设定                            | 理由                                    |
| ---- | ----------------------------- | ------------------------------------- |
| 调仓时点 | 每年 6 月最后交易日                   | A 股年报披露截止次年 4 月 30 日，此时上年年报数据完备，无未来函数 |
| 持有期  | 1 年                           | 符合「股息+市赚率」长期持有定位                      |
| 分组   | 按 PR 升序等分 5 组（Q1 最便宜 → Q5 最贵） | 检验单调性                                 |
| 收益   | 组内等权、qfq 前复权价格比              | qfq 已含分红除权调整，近似总收益（非纯价格）              |
| 基准   | 当年成分股等权年均收益                   | 反映「无脑买入」的机会成本                         |
| 过滤   | 排除 PE<=0、ROE<=0；**PE>300 剔除**；**\|ret_1y\|>5 剔除** | 亏损股排除 + 极端 PE/收益毛刺防污染（V2 新增） |

### V2 修复项（issue #53）

| 修复 | 内容 | 影响 |
|---|---|---|
| P0-1 调仓日 | `rebalance_dates` 改为「6/30 前最近已收盘交易日」语义 | 实际无影响（腾讯周线 6 月末 bar 本就在 6 月末内，新旧 9 年调仓日一致） |
| P0-2 PE 过滤 | 新增 `filter_pe_outliers`（PE_MAX=300） | Q5 PR 上限 14294→660，剔除极端微利股污染 |
| P0-3 收益毛刺 | `\|ret_1y\|>5` 过滤 | **核心修复**：基准 17.26%→7.46%，rho -0.60→-0.90 |
| P0-4 口径澄清 | 明确 qfq ≈ 近似总收益（含分红） | 修正 V1「纯价格收益」错误标注 |

## 四、结论（V2 修订）

1. **「贵 = 危险」有强实证**：Q5（PR>3）9 年平均年化 2.24%，落后基准 5.35 个百分点；绝对区间「高估(>3)」跑输 5.32%。高 PR 组危险成立。
2. **「买最便宜」有超额（V1 结论推翻）**：Q1（最低 PR）年化 13.79%，超额 **+6.20%**。**最低 PR 组确实有 alpha**——修复毛刺后成立。
3. **PR 因子独立于行业**：行业中性化后 Q1 超额仍 **+6.33%**（27 个一级行业覆盖），Q5 仍跑输 -3.38%。**PR 是真实因子，非行业 beta**（这支持 issue #27 行业中性化组合构建）。
4. **估值四档阈值有实证支持**：PR≤1（低估+合理偏低）超额 +4%+，PR>3（高估）跑输 5%+。**项目 `classify_valuation` 的 ≤0.5/0.5-1/1-3/>3 四档方向正确**。
5. **PR 定位：过滤器 + 排名器均可**（V1 只支持过滤器）：
   - 排除高估（PR>2 警惕，>4 危险）→ 有效
   - 挑选最便宜（PR 低）→ **同样有效**（Q1 有 alpha）

### 对后续工作的含义（#27 行业中性化/组合构建）

- Q1 超额行业中性化后稳健 → **行业中性化的低 PR 组合构建值得推进**（#27）
- 绝对区间验证估值四档 → 组合可按 PR 绝对阈值分层

## 六、局限性（解读结果时须注意）

1. **qfq 近似总收益，未含分红再投资**：qfq 价格比已含分红除权调整（近似总收益），但**未计算分红再投资的复利**。高股息组（Q1 常见）实际总收益会比本报告更高。
2. **周线精度**：腾讯周线（qfqweek）调仓日有数日误差（V2 已验证与目标日基本一致，仍非交易日级精确）。
3. **等权而非市值加权**：与真实指数收益口径有差。
4. **行业为当前分类**：T7 用东财当前行业（EM2016）近似历史行业，存在存活偏差；严格需历史行业分类（数据缺口）。
5. **样本**：沪深300（大盘蓝筹）而非全 A；9 年周期未覆盖完整牛熊极值。
6. **成分数据为社区整理**：已抽样核对，非官方数据库；可用 tushare `index_members` 交叉验证。
7. **严格总收益未实现（T8 数据缺口）**：需补拉分红记录（东财 `RPT_SHAREBONUS_DET`）才能算分红再投资，本期未纳入。
