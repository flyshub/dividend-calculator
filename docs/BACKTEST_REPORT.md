# PR 因子历史回测报告

> 对应 issue：#25（PR 因子历史回测脚本）
> 日期：2026-08-08
> 状态：第一版完成（2016-2024，9 年，沪深300 成分）

## 一、回测目的

验证项目核心假设：「市赚率 PR < 0.8 买入能赚钱」是否有实证依据。

- **PR = PE_TTM / ROE_latest**（与 `pr.py` 口径一致：ROE 取最新已披露年报，非 5 年 ROE 中位数）
- 结论驱动后续：PR 有 alpha → 做行业中性化/组合构建（#27）；证伪 → 转向 FCF yield/魔法公式

## 二、方法论

### 口径设计

| 项 | 设定 | 理由 |
|----|------|------|
| 调仓时点 | 每年 6 月最后交易日 | A 股年报披露截止次年 4 月 30 日，此时上年年报数据完备，无未来函数 |
| 持有期 | 1 年 | 符合「股息+市赚率」长期持有定位 |
| 分组 | 按 PR 升序等分 5 组（Q1 最便宜 → Q5 最贵） | 检验单调性 |
| 收益 | 组内等权、纯价格收益 | 与指数口径分离，只看 PR 区分度 |
| 基准 | 当年成分股等权年均收益 | 反映「无脑买入」的机会成本 |
| 过滤 | 排除 PE<=0、ROE<=0 | PR 只对盈利公司有意义（与项目一致） |

### 数据源（全部实测可用）

| 数据 | 来源 | 备注 |
|------|------|------|
| 历史成分 | `unliftedq/index-constitution`（GitHub）`csi300.csv` | opt-in/opt-out 字段，可重建任意历史时点成分；数据源自中证官网公告人工整理，已抽样核对 |
| 历史 PE(TTM) | akshare `stock_zh_valuation_baidu` | 百度股市通估值，覆盖 2001+ |
| 年报 ROE | akshare `stock_financial_analysis_indicator` | 取 12-31 报告期行（仅年报） |
| 价格 | 腾讯 fqkline 周线（qfqweek） | 全球可用，东财 push2his 海外/受限环境易断连 |

### 关键设计：消除幸存者偏差

第一版误用「当前沪深300成分」回测历史收益 → 基准年化虚高至 41%（真实指数同期仅约 5%），结论不可信。

第二版改为**每年用当年 6/30 的真实成分**（含后来被剔除的股票）：
- 2016-2024 每年重建快照，各年 299-300 只，并集 588 只
- 抽样核对：2018-06-30 前 5 成分 `000001/000002/000060/000063/000069` ✓；000009 剔除日 2017-12-11 ✓

## 三、回测结果

### 分组表现（2016-2024，9 年，2538 个有效调仓点）

| 组 | PR 区间 | 年化收益 | 超额(vs基准) | 赢率 | 最差年份 | 夏普 |
|----|---------|---------|-------------|------|---------|------|
| Q1 最便宜 | 0.03-0.98 | 16.91% | -0.67% | 54% | -74.0% | 0.19 |
| Q2 | 0.62-1.93 | 26.17% | +8.59% | 47% | -88.1% | 0.06 |
| Q3 | 1.18-2.96 | **35.68%** | **+18.10%** | 47% | -84.8% | 0.06 |
| Q4 | 1.91-8.01 | 3.38% | -14.20% | 43% | -81.9% | 0.06 |
| Q5 最贵 | 3.97-14294 | 2.86% | -14.72% | 45% | -84.6% | 0.06 |
| **基准** | — | **17.58%** | — | — | — | — |

- 单调性检验：Spearman rho = **-0.60**（PR 越低收益越高，趋势显著）
- Q1（最低 PR）逐年：9 年中 7 年跑赢（2016/2017/2018/2020/2022/2023/2024），2019、2021 跑输

### 与第一版对比（幸存者偏差的影响）

| 指标 | 第一版（当前成分） | 第二版（历史成分） |
|------|-------------------|-------------------|
| 基准年化 | 41.18%（虚高） | **17.58%（真实）** |
| 有效调仓点 | 2198 | 2538 |
| Spearman rho | -0.30 | **-0.60** |
| Q5 超额 | -19.3% | -14.7% |

结论：幸存者偏差会系统性高估所有组的收益、且稀释分组区分度。修正后 PR 的区分度反而增强。

## 四、结论

1. **「贵 = 危险」有实证支持**：Q5（PR>4）9 年平均年化仅 2.9%，落后基准 14.7 个百分点；Q4 也落后 14.2%。
2. **「买最便宜」支持较弱**：Q1 超额 ≈ 0（-0.67%），无脑买最便宜的不是好策略。
3. **超额集中在 Q2/Q3**（PR 约 1~3）：性价比最高区间。
4. **PR 的定位是「过滤器」而非「排名器」**：
   - 用 PR 排除高估股（PR > 2 警惕，> 4 危险）→ 有效
   - 用 PR 挑选最便宜的 → 价值有限

### 对后续工作的含义（#27 行业中性化/组合构建）

- 组合构建应优先用 PR 做**排除条件**（剔除高 PR），而非**选股排名**（买最低 PR）
- 若做行业中性化，应检验 Q2/Q3 的稳定超额是否在行业调整后仍存在

## 五、局限性（解读结果时须注意）

1. **纯价格收益**：未计分红再投资。A 股股息率较高的股票（低 PR 常见）实际总收益会更高，Q1 组可能被低估。
2. **周线精度**：腾讯周线（qfqweek）覆盖 12 年，调仓时点有数日误差。
3. **等权而非市值加权**：与真实指数收益口径有差。
4. **单因子**：未做行业、市值、流动性中性化。
5. **样本**：沪深300（大盘蓝筹）而非全 A；9 年周期未覆盖完整牛熊极值。
6. **成分数据为社区整理**：已抽样核对，但非官方数据库；如追求更强权威性，可用 tushare `index_members` 交叉验证。
