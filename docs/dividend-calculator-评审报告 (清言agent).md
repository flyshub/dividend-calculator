## 一、执行摘要

本报告对 GitHub 开源项目 **flyshub/dividend-calculator**（A股真实股息率与市赚率计算工具）进行深度评审。评审视角聚焦于「能否帮助投资者在股市实战中赚钱」，从方法论、数据准确性、回测有效性、工程质量、实战可用性五个维度全面评估。

项目核心价值在于：以**总额法**计算真实股息率、以 **PE/ROE** 计算市赚率（PR）、以**六维加权模型**评估股息可持续性，并提供四级漏斗选股器。399 个单元测试全部通过，数据口径与公开定义一致，工程质量过硬。

主要风险在于：回测样本仅沪深300+9年、PR 公式时间截面不一致、A+H 股市值口径有瑕疵、部分高股息陷阱识别信号未接入。综合评分 **4/5 星**，适合价值投资者与红利策略投资者作为投研工具使用，但需理解其局限性。

## 二、项目全貌

### 2.1 项目定位

这是一个 A 股真实股息率 + 市赚率（PR = PE/ROE）计算工具，提供三种使用形态：Python CLI、本地 Web 服务、纯前端 GitHub Pages（https://flyshub.github.io/dividend-calculator/）。

项目采用 GPL-3.0 开源协议，技术栈为 Python 3.9+、mootdx（通达信协议）、腾讯行情、ECharts 前端。核心设计理念是「数据铁律」——严禁虚构数据、数据必须有真实来源、口径必须准确、数据必须可验证。

### 2.2 核心功能模块

项目由五大核心模块构成，各模块职责清晰、解耦良好：

| 模块 | 主要文件 | 功能说明 |
|------|---------|---------|
| 股息率计算 | `src/dividend.py` | 总额法 + 最新完整财年 + 三档税率（>1年免税/1月~1年扣10%/<1月扣20%） |
| 市赚率计算 | `src/pr.py`, `pr_calculator.py` | 基础版/修正版(N因子)/PB版 + 估值四档区间 |
| 可持续性评估 | `src/sustainability_calculator.py` | 六维加权评分 + 银行专项模块 + 致命红旗一票否决 |
| 选股器 | `src/screener.py` | 四级漏斗：TTM>5% → 真实>5% → PR≤1 → 可持续 |
| 回测 | `scripts/backtest_pr.py` | 2016-2024 沪深300 PR因子历史回测 |

### 2.3 数据源架构

项目采用多数据源降级链设计，确保全球可用。主数据源不可用时自动降级到备用源，每个数据字段都可追溯到具体来源：

| 数据类型 | 主数据源 | 降级链 |
|---------|---------|--------|
| 实时价格+股本 | 腾讯行情 | 新浪(价) → mootdx finance |
| PE_TTM / PB | 腾讯行情 | 东方财富 push2 |
| 除权除息/分红 | mootdx xdxr | akshare fhps_detail_em → akshare cninfo |
| ROE / 净利润 | mootdx F10 | akshare 同花顺 |
| 行业分类 | mootdx F10 | 东方财富 datacenter |
| 可持续性全部字段 | 东方财富 datacenter | 与 JS 静态版刻意同源 |

## 五、实战赚钱角度的亮点

### 5.1 方法论选择专业，避开常见坑

**总额法 > 每股法**：规避转送股导致每股分红被动变化。转送股（如10送10）后每股分红被动减半，但公司实际分红金额不变，总额法分子分母来自同一截面，不受影响。

**最新完整财年 > TTM（滚动12个月）**：避免跨财年分红混合虚高。例如招行2025/7发2024年报分红 + 2026/1发2025半年报分红，TTM会把两个财年分红加总，虚高股息率。完整财年口径更准确反映公司年度分红能力。

**A+H 股用总股本（腾讯 Index 73）**：不用流通股本。A+H股（如中国银行H股占34.6%）若用流通股本会严重低估总市值、高估股息率。

**三档税率**（>1年免税/1月~1年扣10%/<1月扣20%）贴近A股实际，投资者可按实际持股期限选择对应口径。

### 5.2 PR因子有实证支持（V2修复版）

回测报告 V2 修复了毛刺过滤 bug 后，PR因子展现出显著的预测能力：

| 指标 | V1报告（有bug） | V2修复版 | 修正幅度 |
|------|---------------|---------|---------|
| 基准年化 | 17.58% | 7.59% | -57% |
| Q1超额 | -0.67% | +6.20% | 结论反转 |
| Q5超额 | -14.72% | -5.35% | 修正 |
| Spearman rho | -0.60 | -0.90 | 单调性更强 |

**核心发现**：
- Q1（最低PR）年化 13.79%，超额 +6.20%
- 行业中性化后 Q1 超额仍 +6.33% → PR 是独立 alpha，非行业 beta
- Q5（PR>3）跑输 -5.35% → "贵=危险"成立
- Spearman rho = -0.90（PR越低收益越高，单调性极强）

这是项目最有价值的发现：PR≤1 有超额，PR>3 跑输，估值四档阈值有实证支撑。

### 5.3 可持续性六维模型专业

项目采用「行业路由 → 致命红旗一票否决 → 加权评分 → 情境红旗降档」四层级联结构：

**致命红旗**（一票否决→不可持续）：
- FCF覆盖 < 1.0x（分红超过自由现金流）
- 经营现金流为负却分红
- 亏损却分红（净利润<0且分红>0）
- 银行CAR < 10.5%（监管约束红线）

**六维加权评分**（通用分支）：
- 现金流覆盖（权重25%）：经营CF/分红
- 股利支付率（20%）：分红/净利润
- 盈利能力（15%）：ROE + 利润同比
- 资产负债表（15%）：资产负债率 + 利息保障倍数
- 分红历史（15%）：连续分红年数 + 曾削减
- 行业属性（10%）：周期/防御/成长

**银行专项模块**：资本充足率/净息差/不良率/拨贷比四项专项评分，区别对待金融股。

**情境红旗降档**：支付率>100%、被动高股息（股价跌幅>30%）、突击分红、一股独大+高派息、周期顶点。

### 5.4 工程质量过硬

- **398 Python + 83 JS 单元测试**：覆盖核心业务逻辑
- **`verify_js_vs_python.py` 双端逐字段对齐**：Python与JS实现消费相同原始数据对比
- **多数据源降级链**：mootdx→腾讯→东财→akshare→新浪，全球可用
- **GitHub Actions CI**：每次提交自动跑全部测试
- **每日选股器自动产出**：GitHub Actions 每日生成选股结果页

### 5.5 数据铁律严格，杜绝虚构

项目明确"严禁虚构数据"，数据源不可用即报错，绝不编造。这在金融工具中是稀缺品质——市面上大量"股息率工具"用假数据/示例值糊弄用户。项目四项数据铁律：
1. 严禁虚构数据
2. 数据必须有真实来源
3. 口径必须准确
4. 数据必须可验证

## 六、实战赚钱角度的硬伤与风险

### 6.1 高优先级问题

#### 6.1.1 回测样本严重不足，统计显著性存疑

- **仅沪深300**（大盘蓝筹），未覆盖中小盘/创业板/科创板
- **仅9年（2016-2024）**，未覆盖2008金融危机、2015崩盘、2024-2025 红利行情
- Q1 最差年份 **-68%** → 单年回撤巨大，实战中投资者可能扛不住
- 9年4次跑赢基准（44%胜率）→ 并非稳定跑赢
- **结论**：PR因子方向可信，但"超额+6.2%"是9年平均，非逐年稳定，实战需做好波动预期

#### 6.1.2 回测收益口径不完整

- qfq前复权近似总收益但未含分红再投资复利
- 高股息组（Q1）实际总收益应更高 → 当前回测低估了PR低估值策略的真实收益
- 等权而非市值加权，与真实指数口径有差
- 未考虑交易成本、滑点、流动性（沪深300流动性好，影响小，但需声明）

#### 6.1.3 PR公式时间截面不一致

- `PE_TTM`（含最新季报，滚动12个月）÷ `ROE_latest`（最新年报）
- 分子是TTM时点，分母是年报时点 → 混合两个时间截面
- 文档承认这是"市赚率公式定义口径"，但从严谨量化角度，这是口径瑕疵
- 周期股用5年ROE中位数（PB版）是亮点，但基础版/修正版仍用单年ROE

#### 6.1.4 回测V1曾存在严重bug（质量保障有漏洞）

- V1基准年化 17.58% → V2修复后 7.59%（毛刺收益+12380%未过滤）
- V1结论"Q1无超额"→ V2"Q1有超额+6.20%"（结论完全反转）
- 根因：脚本修复后报告未重新生成，脚本与报告不同步
- **警示**：说明项目质量保障存在流程漏洞，投资者使用回测数字时需保持怀疑

### 6.2 中优先级问题

#### 6.2.1 估值四档阈值泛化性存疑

- ≤0.5低估 / 0.5-1合理偏低 / 1-3合理 / >3高估
- 基于单一市场（A股）+ 单一指数（沪深300）+ 9年回测
- 美股/港股/其他市场是否适用？未验证
- 牛市/熊市不同环境下阈值是否需动态调整？未研究

#### 6.2.2 N因子区间主观

N = 50% / 股利支付率，支付率≥50%→N=1.0，≤25%→N=2.0。阈值 50%/25% 缺乏理论支撑，文档未给出依据。修正版仅适用"ROE稳定+分红大方的价值股"，适用范围窄。

#### 6.2.3 A+H股市值口径问题

用 `A股股价 × 总股本(含H股)`，A 股溢价时高估市值、低估股息率。中国银行 H 股占 34.6%、中国神华 24%，影响显著。文档承认此为已知限制但未修复。

#### 6.2.4 部分情境红旗未触发

- 被动高股息（近1年股价跌幅<-30%）数据未接入，不触发
- 一股独大+高派息（前十大持股>50%且支付率>80%）大股东数据未接入，不触发
- 这两个是高股息陷阱的核心识别信号，缺失削弱了陷阱识别能力

#### 6.2.5 选股器漏斗阈值固定

TTM>5%、真实股息率>5%、PR≤1、可持续性，阈值固定。牛市中符合条件股票少，熊市中多，存在顺周期性。未考虑无风险利率相对水平（如10年期国债收益率），高股息率绝对值意义有限。

### 6.3 低优先级问题

- **缺乏组合层面分析**：单股分析，无组合构建/风险预算/相关性分析，实战需分散持仓
- **缺乏卖出信号**：只有买入信号，无止盈（PR升高到多少卖）、止损（基本面恶化信号），实战"会买不会卖"是常见亏损原因
- **PE_MAX=300过滤可能误杀**：剔除PE>300的股票，但某些高成长股PE高但合理
- **行业中性化用当前行业分类**：东财EM2016当前行业近似历史行业 → 存在存活偏差

## 八、总体评价与实战建议

### 8.1 综合评分

**综合评分：⭐⭐⭐⭐ (4/5) — 优秀的投研工具，但非交易系统**

项目在方法论、数据准确性、工程质量方面表现优秀，但在回测样本、口径一致性、陷阱识别完整性方面存在不足。适合作为价值投资与红利策略的辅助筛选工具，但不能作为唯一决策依据。

### 8.2 适合人群

- **价值投资者**：PR因子有alpha，避贵+选低估值方向正确
- **红利策略投资者**：股息率总额法+可持续性评估，专业且实用
- **长期投资者**：最新完整财年口径，避免TTM虚高
- **A股研究者**：数据源全球可用，双端一致性保障

### 8.3 不适合人群

- **短线交易者**：无择时、无技术面、无情绪指标
- **量化高频**：单因子模型简单，无组合优化
- **风险厌恶者**：Q1最差-68%，波动巨大
- **海外市场投资者**：仅A股，估值阈值未跨市场验证

### 8.4 实战使用建议

基于本次评审，对投资者使用本工具提出以下实战建议：

1. **作为筛选器而非决策器**：PR低≠必买，需结合基本面、行业景气、宏观环境
2. **PR>3坚决回避**：这是回测最稳健的结论（跑输-5.35%）
3. **PR≤1关注但需分散**：单股波动大，需组合持仓降低风险
4. **高股息率必看可持续性**：FCF覆盖<1x、支付率>100%+周期顶点是危险信号
5. **银行股看CAR**：<10.5%监管红线，分红不可持续
6. **A+H股注意市值高估**：股息率可能被低估，需手动校验
7. **回测数字保持怀疑**：V1曾存在严重bug，9年样本不足，超额+6.2%是平均非稳定

### 8.5 核心价值定位

项目最大的实战价值不在于"告诉你买什么"，而在于四个方面：
- **避贵**：PR>3坚决不碰
- **识陷阱**：可持续性评估识别高股息陷阱
- **统一口径**：总额法+完整财年，避免常见计算错误
- **数据透明**：每个数字可追溯，不虚构

## 九、改进建议

### 9.1 短期改进（高优先级）

- 扩大回测样本：增加中小盘、创业板、科创板，延长至2008年
- 修复PR时间截面：统一用TTM ROE或年报PE，避免混合
- 接入被动高股息信号：近1年股价跌幅数据
- 接入大股东持股数据：完善一股独大+高派息识别

### 9.2 中期改进

- A+H股正确市值：接入港股行情，用A股股价×A股股本+H股股价×H股股本
- 组合层面分析：增加相关性矩阵、风险预算、组合优化
- 卖出信号：PR升高到多少止盈、基本面恶化止损
- 动态阈值：根据无风险利率调整股息率阈值

### 9.3 长期改进

- 多市场支持：港股、美股、ETF
- 机器学习增强：用更多因子（FCF yield、魔法公式）补充PR
- 实时风控：持仓监控、基本面恶化预警
- 回测框架升级：支持分红再投资、交易成本、滑点

## 十、结论

dividend-calculator 是一个工程质量过硬、方法论专业、数据准确的 A 股股息率与市赚率计算工具。399 个单元测试全部通过，核心金融指标计算口径与公开定义一致，PR 因子有实证 alpha 支持（Q1超额+6.20%，行业中性化后仍+6.33%）。

主要不足在于回测样本不足（仅沪深300+9年）、PR 公式时间截面不一致、A+H 股市值口径有瑕疵、部分高股息陷阱识别信号未接入。这些不足不影响项目作为投研工具的价值，但投资者使用时需理解其局限性，不可盲目依赖单一指标。

**综合评价：4/5 星**。推荐价值投资者、红利策略投资者、A股研究者使用。使用时遵循"作为筛选器而非决策器、PR>3坚决回避、PR≤1关注但需分散、高股息率必看可持续性"的原则，可显著提升投资决策质量。
