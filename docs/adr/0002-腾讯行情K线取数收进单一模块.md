# 腾讯行情/K线取数收进单一模块

Status: accepted

腾讯行情的 wire 格式、字段索引、单股/批量解析与 fqkline 取数收进 `src/tencent_quote.py` 单一模块（`fetch_tencent_quote` / `fetch_tencent_quote_batch` / `fetch_kline_rows`）；`screener_quotes` 只调用公开批量接口并映射 `QuoteSnapshot`，`api` 与 `eastmoney_fetcher` 通过 `fetch_kline_rows` 取 K 线、各自保留业务语义。

理由：字段索引知识（PE-TTM=39、PB=46、总股本=73）曾散在两处并酿成 CRITICAL（33→39），收拢后一处维护、一处测试；K 线 HTTP 不再重复实现（api 月K / eastmoney 日K / 市场前缀规则统一，北交所前缀顺带修正）。
