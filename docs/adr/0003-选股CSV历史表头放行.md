# 选股 CSV 历史表头放行（防漂移校验保留）

Status: accepted

`export_screener_json.py` 的 `parse_csv` 表头校验从「严格等于 FIELDS」放宽为：新 FIELDS 严格相等，或**已知历史表头**（11 列旧 FIELDS 全等）放行、缺失的新列按空处理。

理由：新增「股东总回报率%」列（12 列契约）后，保留期内（默认 90 天）的历史 11 列 CSV 在原严格校验下会令整次导出在第一个文件处崩溃，每日 CI 持续红最长 90 天；而历史行情不可回溯重算。防漂移初衷保留——只放行已知历史表头，任意其他缺列/换列/多列仍报错；按日 JSON 中新列缺失渲染为空白，历史曲线上该指标自上线日起积累。

Considered Options:
- A（采纳）：白名单放行已知历史表头（11 列全等），其余严格。
- B：删除历史 11 列 CSV，从上线日重新积累。违背「宁留不误删」保留精神，history 曲线断档。
- C：选股页运行时现算、不落 CSV 列。兼容问题换形态不消失（页面仍缺 PB 输入），且 CSV 失去快照自包含性。
