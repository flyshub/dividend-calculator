# 数据可靠性 / 真实性 / 准确性审查报告

> 从金融角度对本项目数据质量的一次全面审查。数据可靠性、真实性、准确性是项目生命线（数据铁律，见根 `CLAUDE.md`「关键约束」）。
>
> 审查日期：2026-08-07。本文档记录审查结论、数据源口径、风险分级与修复路线图，供维护参考。

## 1. 数据铁律

> 四项铁律是本项目**最高优先级约束**，违反即禁止合并。详见根 `CLAUDE.md`「关键约束」段。

1. **严禁虚构数据** — 数据源不可用返回错误，绝不编造、推算补缺、伪造示例值。
2. **数据必须有真实来源** — 每个字段可追溯到具体数据源；来源不可用即报错或明确标注缺失。
3. **口径必须准确** — 金融指标计算口径与公开定义一致；文档公式与实现逐字一致，发现不一致立即修正。
4. **数据必须可验证** — 新增/修改数据功能前先验证可获得性与真实性；涉及数据的代码必须配测试。

### 数据功能先验证（开发纪律）

任何涉及数据的功能，落地前必须完成：

| 验证项 | 内容 |
|--------|------|
| 可获得性 | 数据源接口可访问、返回结构符合预期、数据非空 |
| 真实性 | 抽样与公开信息核对（真实股票、真实财报数字），严禁用假数据测试 |
| 准确性 | 口径正确、与既有实现双端一致、字段映射实地验证过 |
| 回归 | 跑通 `python -m pytest tests/ -q`、`node --test site/js/calculator.test.js`、`python scripts/verify_js_vs_python.py` 三项 |

## 3. 核心金融指标口径（已验证）

| 指标 | 实际口径 | 来源 |
|------|---------|------|
| 真实股息率 | 最近完整财年现金分红总额 / 当前总市值（总额法） | `src/dividend.py` |
| 市赚率基础版 | **PE_TTM / ROE_latest**（最新年报 ROE，非 5Y 中位数） | `src/pr.py:415` |
| 市赚率修正版 | N × PE_TTM / ROE_latest | 同上 |
| PB-市赚率 | PB / ROE² × 100（周期股用 5 年 ROE 中位数，非周期股用最新年报 ROE） | `src/pr.py` |
| **口径标注（P0-2）** | PE 为 TTM（含最新季报），ROE 为最新年报（`roe_period` 标注报告期，如 '2025年报'）——ROE 仅定期披露无实时值，与 PE 组合是市赚率公式的定义口径，已在 PR 结果/前端标注 | `src/pr.py` PRResult.roe_period |
| N 因子 | 0.5 / 股利支付率，区间 [1.0, 2.0] | `src/pr.py` |
| 股利支付率 | 分红总额 / 最新年报净利润 | `src/pr.py` |
| 可持续性六维 | 东财 MAINFINADATA 仅 12-31 年报行 | `src/sustainability.py` |
| 曾削减判定 | 近 10 年窗口内相邻年降幅 > 30% | `src/sustainability.py` |

## 5. 已确认做对的机制（维护时勿破坏）

- **严禁虚构**：数据源不可用 → None/空数组/错误，多模块一致，有测试
- **防错配**：财务只留 12-31 年报行；分红进度过滤（排除预案）；`_to_float` 空串防 0 污染
- **双端对齐**：可持续性模块与 JS 静态版同源（东财 datacenter），`verify_js_vs_python.py` 逐字段校验
- **已知字段坑已规避**：NON_PERFORMING_LOAN 是余额非比率、RISK_COVERAGE 恒 None、DEBT_ASSET_RATIO 不存在等（`_FIELD_MAP` 注释标注）
- **财年判断**：`infer_fiscal_year` 10 个测试全覆盖；两套口径交叉校验见 `tests/test_fiscal_year_crosscheck.py`（#14）

**两套财年口径分工**（#14 固化，防静默破坏；#100 后报告期口径收敛为单一实现 `sustainability.classify_fiscal_report`，`dividend_records` 各 adapter / `parse_dividend_rows` 均经它）：

| 判定源 | 输入 | 语义 | 规则 |
|--------|------|------|------|
| `utils.infer_fiscal_year` | 除权月 | 财年归属 | 3-8月→上年年报；9-12月→当年中报；1-2月→上年中报 |
| `sustainability.classify_fiscal_report`（经 `parse_dividend_rows` / `dividend_records`） | 报告期月 | 报告期类型 | 12月→年报；3/6/9月→中期分配 |

已知不一致场景（结构性，非 bug）：跨年除权（除权日 1-2月 vs 报告期 12-31）、Q1 特别分红（报告期 3-31 vs 9-12 月除权）、年中特别分红（报告期 6-30 vs 次年 4 月除权）。差异来自输入信号不同（mootdx 只给除权日、东财只有报告期），不可强行统一。
